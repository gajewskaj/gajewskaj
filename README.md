## 🚀 Open source
While working on my Master's thesis, I came across and **independently investigated a GPU performance bottleneck** in `SuperLU.solve()` (CuPy's `sparse` module) using **NVIDIA Nsight Systems** and **NVIDIA Nsight Compute**. I later found a CuPy [PR #10224](https://github.com/cupy/cupy/pull/10224) addressing the same issue, shared my profiling results, and validated the proposed fix on different data and hardware ([my profiling & validation](https://github.com/cupy/cupy/pull/10224#issuecomment-5777493410)).
